# AI Pronunciation Coach

An interactive web app that listens to your voice, scores your pronunciation accuracy, and gives word-by-word visual feedback.

## 🛠️ Local Setup

1. Install the required libraries:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
streamlit run app.py
```

## 🕹️ How to Use

1. **Choose Mode:** Select **Challenge Pool** for leveled sentences or **Custom Text** to type your own.
2. **Listen:** Click the audio player to hear the native guide pronunciation.
3. **Record:** Click the microphone button and read the sentence out loud.
4. **Analyze:** Click **Analyze** to see your accuracy score, words highlighted in green (correct) or red (incorrect), and your progress history.
